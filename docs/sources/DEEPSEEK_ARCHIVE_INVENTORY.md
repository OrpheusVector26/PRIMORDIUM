## Safe extraction

The archive’s useful engineering themes were distilled into reviewable repository artifacts:

- policy-first and evidence-first boundaries
- explicit capability and truth/confidence labels
- typed agent handoffs and bounded budgets
- A2A v1.0 card validation and negotiation
- stdlib-first, rootless sandbox design
- honest distinction between generated, verified, and merely proposed integrations

## Excluded material

Raw chat bodies, account metadata, personal identifiers, legal/investigative records, credentials, bearer tokens, and provider-specific secrets were not copied. The repository must remain safe to publish publicly.
